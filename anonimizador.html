3 · Modelo de linguagem (NER) opcional

Opcional. Com o pacote NER (BERTimbau), a detecção entende o contexto e acha nomes, endereços e outros dados que as regras não pegam. Selecione a pasta anonlab-ner ou arraste-a para cá.

Onde consigo o pacote? É seguro?

O pacote é uma pasta gerada uma vez, numa máquina com internet, por tools/build_ner_pack.py (veja o README), e copiada para cá. Contém o modelo convertido para ONNX e o runtime (transformers.js + onnxruntime-web). Tudo roda neste computador: GPU via WebGPU ou CPU via WebAssembly. O runtime só é executado se o SHA-256 conferir com o fixado neste arquivo, e a política de segurança da página bloqueia qualquer acesso à rede.

Como funciona / privacidade

Cinco camadas: padrões (CPF, e-mail, telefone… com validação de dígito), modelo de linguagem (NER BERTimbau, opcional), listas (estados, capitais, países), heurística de nomes e seus termos livres. O que o modelo acha é procurado no resto do texto, para nenhuma ocorrência escapar. A ferramenta sugere; você decide. Roda 100% no navegador, offline. Veja claude.md para o design completo.
