3 · Modelo de linguagem (NER) opcional

Opcional. Com um modelo de linguagem (BERT), a detecção entende o contexto e acha nomes, endereços e outros dados que as regras não pegam. O modelo vem até o navegador; o seu texto não vai a lugar nenhum. O primeiro download é grande (~490 MB na GPU, ~970 MB na CPU) e fica guardado para as próximas vezes.

De onde vem o modelo? É seguro?

Dois modelos já publicados em ONNX no Hugging Face, numa revisão fixa: legal-bert-ner-base-cased-ptbr (dominguesm, CC-BY-4.0; ONNX de augustaklug) e OpenMed PII Portuguese (OpenMed, Apache-2.0). O runtime (transformers.js + onnxruntime-web) vem do jsDelivr e só é executado se o SHA-256 conferir com o fixado neste arquivo. Tudo roda neste computador: GPU via WebGPU ou CPU via WebAssembly. A política de segurança da página só permite conectar a esses dois serviços, e só para baixar arquivos; o documento nunca é enviado. Sem internet? Use pasta local com o pacote gerado por tools/build_ner_pack.py (veja o README).

Como funciona / privacidade

Cinco camadas: padrões (CPF, e-mail, telefone… com validação de dígito), modelo de linguagem (NER, opcional), listas (estados, capitais, países), heurística de nomes e seus termos livres. O que o modelo acha é procurado no resto do texto, para nenhuma ocorrência escapar. A ferramenta sugere; você decide. Roda 100% no navegador: a rede só baixa o modelo, e o texto não sai daqui. Veja claude.md para o design completo.
